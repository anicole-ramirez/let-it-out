# Let it out!

This is an AI generated game done for the claude code community game jam in Berlin. Design: [DESIGN.md](DESIGN.md).

Single player: https://abdbarho.github.io/let-it-out/

## Run

```
npm install
npm run dev
```

Open `http://localhost:3000/screen` on the projector; phones on the same Wi-Fi scan the QR code.
